===========================================================
  ARGUS Eye Guard -- Prerequisites & System Requirements
===========================================================

-----------------------------------------------------------
SYSTEM REQUIREMENTS
-----------------------------------------------------------
- OS            : Windows 10/11 (64-bit) or Ubuntu 22.04+
- RAM           : 16 GB minimum (32 GB recommended for emulator + analysis)
- Disk          : 20 GB free space
- Python        : 3.12
- Node.js       : 18+ (for the frontend)
- Java          : JDK 11+ (required by JADX and APKTool)
- Docker        : Docker Desktop 4.x (if using Docker deployment)
- ADB           : Android Debug Bridge (part of Android SDK Platform Tools)


-----------------------------------------------------------
PREREQUISITES -- SOFTWARE TO INSTALL
-----------------------------------------------------------

1. Python 3.12
   https://www.python.org/downloads/

2. Node.js 18+
   https://nodejs.org/

3. JDK 11+
   https://adoptium.net/

4. Docker Desktop
   https://www.docker.com/products/docker-desktop/

5. Android Studio (for emulator / dynamic analysis)
   https://developer.android.com/studio

   Inside Android Studio:
   - Open SDK Manager -> SDK Platforms
   - Install: Android 13.0 (API Level 33)
   - Open SDK Manager -> SDK Tools
   - Install: Android Emulator, Android SDK Platform-Tools, Intel HAXM

   Create a Virtual Device (AVD):
   - Device   : Pixel 6
   - System   : API 33 (Android 13, x86_64)
   - RAM      : 4096 MB
   - Enable   : Cold Boot

   Start the emulator and confirm ADB sees it:
     adb devices

6. Frida server -- auto-downloaded by the app on first dynamic analysis run.

7. JADX and APKTool are bundled under tools/ -- no separate install needed.

8. MobSF -- pulled automatically via Docker (see DEPLOYMENT.txt).


-----------------------------------------------------------
REQUIRED API KEYS -- create analysis/.env
-----------------------------------------------------------

Create the file analysis/.env and fill in your keys:

  DEEPSEEK_API_KEY=<your_deepseek_key>
  VIRUSTOTAL_API_KEY=<your_virustotal_key>
  MOBSF_URL=http://localhost:8000
  MOBSF_API_KEY=argus_mobsf_key_12345
