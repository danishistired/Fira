FIRA — PREREQUISITES
====================

CORE REQUIREMENTS
----------------

- Docker Engine with Docker Compose v2 (for the backend container)
- Android SDK Platform Tools (ADB)
- Android Emulator with an x86_64 Google APIs system image
- A rootable AVD; Google Play emulator images generally do not support adb root
- Hardware acceleration/KVM for practical emulator performance
- DeepSeek API key for LLM-guided exploration

The backend image installs the Python dependencies, including Androguard,
OpenJDK 17, ADB, JADX, and Apktool. JADX and Apktool are fetched as pinned
releases during the image build; they do not need to be committed as binaries.
For local non-Docker backend development, install Python 3.12 and Java 17+,
then run download_tools.ps1 to fetch the local analyzer tools.


ANDROID EMULATOR
----------------

In Android Studio's SDK Manager, install:

- Android SDK Platform Tools
- Android Emulator
- Android 13 / API 33 platform
- Android 13 / API 33 Google APIs x86_64 system image

Create an AVD with the Google APIs image (not Google Play). Start it and verify:

  adb -a start-server
  adb devices
  adb root

The Docker backend needs access to the host ADB server on TCP port 5037. Allow
that port only from the local Docker bridge; never expose it publicly. For AWS,
use an EC2 host where /dev/kvm is available and `emulator -accel-check`
succeeds. The emulator runs on the host, not inside the analysis container.


OPTIONAL SERVICES AND KEYS
--------------------------

- VIRUSTOTAL_API_KEY — optional reputation lookup
- MobSF — optional secondary static analysis, enabled with the Compose `mobsf`
  profile. Configure MOBSF_API_KEY if it is used.

Do not commit .env files, API keys, APK uploads, databases, or analysis
artifacts. See DEPLOYMENT.txt for local Compose, Docker Hub, and AWS steps.
