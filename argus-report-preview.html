Executive Summary
Package com.boi.mpay is the official Bank of India mobile banking application, signed with a Google Play App Signing certificate (4096-bit RSA, META-INF/GOOGPLAY.RSA). All embedded network endpoints resolve to bankofindia.co.in infrastructure, including the UPI gateway at uping.bankofindia.co.in. SMS capability detected in code exists for OTP autofill during login and UPI transactions, implemented in Sms.java — no evidence of SMS content being forwarded to any external endpoint. Analyst Takeaways
Identity confirmed. The package is signed with a Google Play App Signing certificate and connects exclusively to bankofindia.co.in and boi-mpay-new.firebaseio.com. Built by Infrasoft Technologies, the official Bank of India technology partner. SMS permissions are legitimate. READ_SMS, RECEIVE_SMS and SEND_SMS are used by SmsReceiver for OTP autofill during login and UPI transactions — standard behaviour for Indian banking and UPI apps. No code path forwards SMS content off-device. Active security measures. Certificate pinning against the bank's own server certificates, root/tamper detection via RootBeer, biometric authentication, and NPCI's official UPI security component. Two minor notes. Some embedded SSL certificates carry 2022–2024 expiry dates, which indicates runtime certificate refresh or server-side rotation. This APK build dates to June 2023 — installing the current Play Store version is preferable to sideloading this file.
